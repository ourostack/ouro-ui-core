# Free CI and build resources

What Ouro's repositories can use at no cost, what each fits, and how to switch it on. Checked 2026-11-03.

## GitHub Actions: standard runners, free in public repositories

- Standard GitHub-hosted runners in public repositories are free and don't use any included minutes. Larger runners are billed, even in public repositories. Source: [GitHub Actions billing](https://docs.github.com/billing/managing-billing-for-your-products/managing-billing-for-github-actions).
- `xcode-27` is a standard arm64 macOS label (3 CPU, M1, 7 GB). `xcode-27-xlarge` is the larger, billed one (M2, 5 CPU). Sources: [the Xcode 27 image changelog](https://github.blog/changelog/2026-07-16-xcode-27-runner-image-now-in-public-preview/), [GitHub-hosted runners reference](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).
- The image carries Xcode 27.0, 27.1 (default) and 27.2 (release candidate), with iOS 27.0 to 27.2 simulators. Source: [xcode-27-arm64 readme](https://github.com/actions/runner-images/blob/main/images/macos/xcode-27-arm64-Readme.md).
- Fits: every Apple build, test, DocC and gallery job in a public repository. Switch on: `runs-on: xcode-27`. Never use `-large` or `-xlarge` without a cost decision.
- Limit: GitHub adds a new Xcode beta to the image some days after Apple ships it.

## Xcode Cloud: 25 compute hours a month with the Apple Developer Program

- Every Apple Developer Program membership includes 25 Xcode Cloud compute hours a month. More hours are a paid subscription, from US$49.99 a month for 100 hours. Source: [Xcode Cloud](https://developer.apple.com/xcode-cloud/).
- Ouro uses Ari's personal Apple Developer account for this, never his Microsoft work account.
- Xcode Cloud can't build a Swift package on its own. It builds a package as a local package of an app project or workspace. Source: [Building Swift packages with Xcode Cloud](https://developer.apple.com/documentation/xcode/building-swift-packages-or-swift-playground-app-projects-with-xcode-cloud).
- Fits: jobs that need an Xcode beta before GitHub's image has it (ouro-ui-apple's Siri AI job needs Xcode 27.3, whose beta 1 shipped 2026-11-03, per its [release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-27_3-release-notes)), and TestFlight delivery of an example app.
- Switch on: the personal account's Account Holder, an Admin or an App Manager creates the first workflow in Xcode. That links the GitHub repository through the Xcode Cloud GitHub app and creates an App Store Connect app record. Commit the app project (the gallery's is generated by XcodeGen today) and `Package.resolved`. After that, the App Store Connect API (`ciProducts`, `ciWorkflows`, `ciBuildRuns`) can start and read builds unattended. Source: [Get started with Xcode Cloud](https://developer.apple.com/xcode-cloud/get-started/).
- Budget: at 25 hours, keep it to the jobs GitHub can't run yet, on main and releases.

## Visual Studio subscription: Azure credit and Azure DevOps

- Up to US$150 of Azure credit a month, depending on the subscription, and Azure DevOps Basic access. Source: [What are Visual Studio Subscriptions?](https://learn.microsoft.com/en-us/visualstudio/subscriptions/what-are-subscriptions).
- Azure Pipelines' free tier is one Microsoft-hosted job, up to 60 minutes a run and 1,800 minutes a month. New public projects can no longer be created. Source: [Configure and pay for parallel jobs](https://learn.microsoft.com/en-us/azure/devops/pipelines/licensing/concurrent-jobs?view=azure-devops).
- Fits: nothing in Ouro today. GitHub's free standard runners already cover more, and Azure has no macOS virtual machines to spend the credit on. Revisit if a repository goes private and runs out of GitHub minutes.
